# vIA Pyrénées — site internet

Site statique (HTML/CSS, sans base de données) du collectif vIA Pyrénées : https://viapyrenees.fr

## Pages
- `index.html` — accueil
- `enjeux.html` — vos enjeux
- `approche.html` — notre approche et nos offres
- `collectif.html` — le collectif
- `evenements.html` — nos événements (Cafés IA)
- `diagnostic.html` — autodiagnostic « Où en êtes-vous avec l'IA ? »
- `contact.html` — nous contacter
- `mentions-legales.html` — mentions légales et politique de confidentialité

Les images et le favicon sont dans `assets/`. Les formulaires ouvrent la messagerie du visiteur vers contact@viapyrenees.fr (aucun serveur nécessaire).

## Mise en ligne
Copier le contenu du dépôt à la racine du site (dossier `public_html` sur Hostinger). Aucune compilation n'est nécessaire.
